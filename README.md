# claude-usage-window-scheduler

Claude（Pro / Max プラン）の **5時間利用枠** を、毎日 **10:00〜19:00 の間に3回** 使えるように、
GitHub Actions から自動で短いメッセージ（ping）を送って枠を開始させる仕組みです。
GitHub のサーバー上で動くため、**PC をシャットダウンしていても動作します。**

## 仕組み

5時間枠は「その枠で最初にメッセージを送った時刻」から始まります。
10:00 に初めて使うと枠は 10–15 / 15–20 の **2回** しか取れません。
そこで朝のうちに ping を送って枠を前倒しで開始させます。

| ping 時刻 (JST) | 枠 | 10:00〜19:00 で使える時間 |
|---|---|---|
| 07:05 | 07:05〜12:05 | 10:00〜12:05（約2h） |
| 12:07 | 12:07〜17:07 | 5h |
| 17:09 | 17:09〜22:09 | 17:09〜19:00（約2h） |

- ワークフローは JST 05:05〜19:35 の間、30分ごとに起動します。
- `scripts/ping.py` が「今 ping すべきか」を判定します。
  - その日の1回目は `FIRST_PING_TIME`（既定 07:00）以降の最初の実行で送信
  - 2回目以降は、前回 ping 成功から 5時間 + 2分 経過したら送信（15分以内なら待機してぴったりに送信）
- ping 成功時刻は `state/last_ping.json` にコミットされます（このコミットは「60日間無活動でスケジュール停止」の対策も兼ねます）。
- ping は `claude -p` で Haiku に1往復だけ送るので、消費トークンはごくわずかです。
- 上限到達などで ping が失敗した場合は記録せず、次回の実行で再試行します。

## セットアップ

1. **OAuth トークンを発行する**（手元の PC で1回だけ）
   ```bash
   npm install -g @anthropic-ai/claude-code
   claude setup-token
   ```
   表示された `sk-ant-oat01-...` のトークンをコピーします（Claude のサブスクリプション枠を使う長期トークンです）。

2. **リポジトリの Secret に登録する**
   Settings → Secrets and variables → Actions → **New repository secret**
   - Name: `CLAUDE_CODE_OAUTH_TOKEN`
   - Value: 手順1のトークン

3. **Actions を有効化する**
   Actions タブを開き、ワークフローが無効になっていれば有効化します。

4. **動作確認**
   Actions → *Claude usage window ping* → **Run workflow** で `force` にチェックを入れて実行し、
   成功して `state/last_ping.json` が更新されることを確認します。
   その後 claude.ai の 設定 → 使用状況 で枠のリセット時刻が更新されていれば OK です。

## 設定（任意）

Settings → Secrets and variables → Actions → **Variables** で上書きできます。未設定なら既定値が使われます。

| 変数 | 既定値 | 説明 |
|---|---|---|
| `FIRST_PING_TIME` | `07:00` | 1回目の ping を送る時刻。05:01〜08:59 なら 10–19時に3枠入る。早いほど1枠目が短く3枠目が長くなる |
| `LAST_PING_TIME` | `18:50` | これ以降は ping しない |
| `MAX_PINGS_PER_DAY` | `3` | 1日の最大 ping 回数 |
| `MARGIN_MINUTES` | `2` | 5時間に足す余裕（分） |
| `MAX_WAIT_MINUTES` | `15` | 次の ping 時刻がこの分数以内ならジョブ内で待機する |
| `ACTIVE_DAYS` | `1,2,3,4,5,6,7` | 稼働曜日（1=月 … 7=日）。平日のみなら `1,2,3,4,5` |
| `PING_MODEL` | `haiku` | ping に使うモデル |
| `TIMEZONE` | `Asia/Tokyo` | タイムゾーン |

## 注意点

- **GitHub Actions の cron は数分〜数十分遅れることがあります。** 遅れても前回成功時刻を基準に次を計算するので、3枠が 10–19時に収まるよう余裕を持たせています。
- **手動で使った時刻は検知できません。** 例えば 06:30 に自分で Claude を使うと枠は 06:30 に始まり、07:05 の ping はその枠の中で送られます。この場合も自分の利用で次の枠が始まるだけなので大きな問題はありません。
- **Actions の無料枠**: private リポジトリは月 2,000 分まで無料です。本ワークフローは1日約30回（ほとんどは数秒で終了、1回1分換算）なので月 900〜1,300 分程度です。public リポジトリなら無制限で無料です（トークンは Secret なので公開されません）。
- 枠の仕様（5時間・開始時刻の扱い）は Anthropic 側で変わる可能性があります。
